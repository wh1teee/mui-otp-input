# `@wh1teee/mui-otp-input` 8.0.0-next.0

This prerelease synchronizes the maintained fork with upstream v7 and introduces renderer-independent OTP behavior for MUI and Base UI / shadcn applications.

## Included

- Existing root imports remain MUI-compatible; `/mui` is the explicit alias.
- Upstream MUI 9 support is included while MUI 7 + React 18 remains qualified.
- `/base-ui` and `/shadcn` expose Base UI OTP primitives and a complete accessible field.
- `/headless` provides UI-independent normalization utilities.
- MUI and Base UI React Hook Form adapters are published as separate subpaths.
- Fork behavior remains covered: delayed autofocus, character transformation, paste preprocessing, stable native refs, and empty-slot focus routing.
- The opt-in shadcn stylesheet is scoped to semantic `data-slot` selectors and does not define global tokens or remote assets.

## Qualification

- Chromium, Firefox, and WebKit input, paste, autofill replacement, keyboard, form, viewport, and automated WCAG checks.
- Strict declaration and SSR/runtime consumers from the exact tarball.
- MUI 7 + React 18 and MUI 9 + React 19 matrices.
- MUI consumers without Base UI installed and Base UI consumers without MUI/Emotion installed.
- Byte-identical registry artifact and npm provenance verification in the release workflow.

This is a prerelease published under the `next` dist-tag. It does not replace `latest`.
