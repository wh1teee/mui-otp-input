# `@wh1teee/mui-otp-input` 9.0.0

This major release renders the `/shadcn` entry as **one real `<input>`** with
the cells drawn over it, the model of `input-otp` and shadcn/ui. SMS autofill
(`autocomplete="one-time-code"`), keyboard suggestions on iOS and Android,
password managers, WebOTP, screen readers and paste all see a single field,
as current guidance for SMS codes asks. `/base-ui` and the Material UI
component keep their per-cell rendering and public API.

## `/shadcn`: one input

- `InputOTP` renders one transparent `<input>` (`type="text"`, `inputmode` and
  `pattern` from `validationType`, `autocomplete="one-time-code"`,
  `maxlength={length}`) over the cells. `id`, `name`, `form`, `disabled`,
  `readOnly`, `required`, `enterKeyHint`, `aria-*` and event handlers go to that
  input; `className`, `style` and `data-*` stay on the root.
- `InputOTPSlot` is a drawn cell, hidden from assistive technology. It shows the
  character and sets `data-active`, `data-filled`, `data-fake-caret`,
  `data-invalid` and `data-disabled`; `data-slot="input-otp-slot"` is kept.
  `useInputOTPSlot(index)` returns the same state for custom cells.
- The active cell follows the input's selection: the caret sits after the last
  character, a selected range highlights every selected cell, and clicking or
  tapping a cell moves the caret there, never past the value. A caret blinks in
  the active empty cell and stops blinking under `prefers-reduced-motion`.
- Digits always run left to right, also on right-to-left pages.
- Typing, Backspace/Delete, arrow keys, Home/End, select-all, paste of a whole
  or partial code (spaces and dashes are dropped), one-event autofill, IME
  composition and a controlled value set from outside go through the same
  normalization as before (`validationType`, `transformChar`, `validateChar`,
  `normalizeValue`, `pastePreprocess`). A pasted or autofilled whole code
  replaces the field wherever the caret was.
- Password managers: as in `input-otp`, when a password-manager badge appears
  and there is room, the input grows 40px into a clipped gutter past the last
  cell, so the badge sits beside the cells instead of over them.
- `/shadcn` no longer needs `@base-ui/react`. `/shadcn/react-hook-form` is its
  own entry and binds the single input (`field.ref` is the input).

## New

- `onComplete(value)` fires once each time the value becomes complete: not on
  mount, not again for the same value, and again after the value passed
  through an incomplete one. A complete value set from outside (WebOTP) counts.
  `autoSubmit` submits the owning form with `requestSubmit()` on that edge.
- The `ref` of `InputOTP` and `OtpInput` is a handle:
  `clear({ focus?: boolean })`, `focus()`, `root`, `input`.
- `requestWebOtp({ length, signal, transport })` and `isWebOtpSupported()` in
  `/headless` (React-free, `null` where unsupported or on a malformed code).
- `useWebOtp({ enabled, length, onCode, transport })` in `/shadcn` and
  `/base-ui` requests the code, calls `onCode` once with a valid code, aborts
  when `enabled` turns false or on unmount, and returns `{ abort }` for submit
  or resend. A no-op on the server and where `OTPCredential` is missing.

## Migration from 8.x (`/shadcn` only)

Nothing changes for `/base-ui`, `/base-ui/react-hook-form`, the root and `/mui`
entries. To keep the per-cell field, import from `/base-ui` instead of
`/shadcn`.

`InputOTPSlot` no longer accepts input attributes. Each removed prop moves to
the root, which forwards it to the single input:

| Removed `InputOTPSlot` prop                                                                    | Now                                                                                                                                                                                             |
| ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `aria-label`, `aria-labelledby`                                                                | One name for the field on `InputOTP` (or a `<label htmlFor>` pointing at its `id`); cells have no names.                                                                                        |
| `aria-describedby`, `aria-invalid`, `aria-*`                                                   | `InputOTP`. `aria-invalid` also sets `data-invalid` on every cell.                                                                                                                              |
| `type` (for example `"password"`)                                                              | `mask` on `InputOTP`; the input stays `type="text"` so autofill keeps working.                                                                                                                  |
| `autoComplete`, `inputMode`, `enterKeyHint`, `id`, `name`, `form`                              | `InputOTP`.                                                                                                                                                                                     |
| `disabled`, `readOnly`, `required`, `autoFocus`                                                | `InputOTP` (applies to the whole code; there are no per-cell read-only cells).                                                                                                                  |
| `placeholder`                                                                                  | Draw it in empty cells, for example `[data-slot='input-otp-slot']:not([data-filled])::before`, or with `useInputOTPSlot`.                                                                       |
| `onChange`, `onInput`, `onCompositionEnd`                                                      | `onValueChange(value, details)` on `InputOTP`.                                                                                                                                                  |
| `onKeyDown`, `onKeyUp`, `onPaste`, `onFocus`, `onBlur`, `onMouseDown`, `onClick`, other events | `InputOTP` (they receive the input's events).                                                                                                                                                   |
| `ref` (`HTMLInputElement`)                                                                     | The slot `ref` is now its `<div>`; the input is `inputRef` on `InputOTP` or `ref.current.input`.                                                                                                |
| `render`, `className`/`style` as functions of state                                            | `className`/`style` are plain values; style state with `data-active`, `data-filled`, `data-fake-caret`, `data-invalid`, `data-disabled`, or render your own cell with `useInputOTPSlot(index)`. |

Other `/shadcn` changes:

- `InputOTP` `ref` is the handle above (was the root `<div>`, now
  `ref.current.root`). `onValueComplete` is replaced by `onComplete(value)`.
  `onValueChange` details are `{ reason, event, cancel(), isCanceled }` with
  reasons `input-change`, `input-clear`, `input-paste` and `imperative`;
  `onValueInvalid` details are `{ reason, event }`. Base UI root-only props
  (`render`, state functions for `className`/`style`) are gone.
- `OtpInput`: `slotAriaLabel` is removed (the label names the input);
  `slotProps` are cell (`<div>`) props; `ref` is the handle.
- `InputOTPSeparator` is hidden from assistive technology (no
  `role="separator"`).
- The `InputOTPRootProps` type is exported from `/base-ui` only.

## Size

Entrypoint budgets (gzip, peers external), measured against 8.1.0:

- `/shadcn`: 3,428 → 5,867 bytes, but it no longer pulls Base UI's OTP Field
  (about 11.5 KB gzip), so an app using only `/shadcn` ships roughly 9 KB less.
  Budget 6.15 KB.
- `/shadcn/react-hook-form`: 5,741 bytes (new entry). Budget 6 KB.
- `/base-ui`: 3,428 → 3,906 bytes for the added `useWebOtp`. Budget 4.05 KB.
- `/base-ui/react-hook-form`: 3,653 → 3,791 bytes; budget unchanged.
- `/headless`: 801 → 1,027 bytes for `requestWebOtp`. Budget 1.1 KB.
- MUI entries are unchanged.
