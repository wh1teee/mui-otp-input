# `@wh1teee/mui-otp-input` 8.0.1

This patch moves the repository, declaration checks, examples, and exact
consumer matrix to the stable native TypeScript 7 compiler. OTP runtime bytes,
public props, renderer boundaries, keyboard behavior, autofill handling, form
semantics, and CSS contracts are unchanged from 8.0.0.

## TypeScript 7 toolchain

- `tsc` resolves to TypeScript `7.0.2` in the root package and docs workspace.
- tsdown, Docusaurus, ESLint integrations, and any other tools that still embed
  the compiler API receive Microsoft's official
  `@typescript/typescript6@6.0.2` compatibility package through an npm alias.
- The compatibility package is not used for project type-checking. A dedicated
  executable contract proves the native TypeScript 7 binary, compatibility API,
  docs compiler, and exact packed consumer topology.
- Isolated React 18/19, MUI 7/9, Base UI, React Hook Form, Next.js 16 and SSR
  consumers compile against the exact tarball using the same toolchain boundary.

This follows the TypeScript team's production guidance while TypeScript 7's
programmatic API remains unstable. It avoids holding the actual compiler on the
legacy JavaScript implementation solely for build tools that inspect TypeScript.

All existing unit, Chromium/Firefox/WebKit, automated WCAG, package boundary,
bundle budget, Next.js, docs/Storybook, OIDC provenance and registry byte-parity
gates remain mandatory.
