# `@wh1teee/mui-otp-input` 8.0.0

This is the stable v8 release of the maintained fork. It synchronizes the MUI renderer with upstream v7, qualifies MUI 7/9 and React 18/19, and freezes renderer-independent OTP behavior for MUI and Base UI / shadcn applications.

## Stable public surface

- Existing package-root imports remain MUI-compatible; `/mui` is the explicit renderer alias.
- `/base-ui` and `/shadcn` expose Base UI OTP primitives and a complete accessible field.
- `/headless` provides normalization and completion utilities with no React or UI runtime.
- Explicit React Hook Form adapters are published at `/mui/react-hook-form`, `/base-ui/react-hook-form`, and `/shadcn/react-hook-form`; the historical `/react-hook-form` path remains compatible.
- The opt-in shadcn stylesheet is scoped to semantic `data-slot` selectors and defines no reset, remote asset, or global token.

## Behavior retained

Delayed autofocus, `transformChar`, paste preprocessing, native one-time-code replacement, stable refs, empty-slot focus routing, native form submission/reset, keyboard navigation, controlled/uncontrolled ownership, and opt-in auto-submit share one behavior contract across renderers.

## Bundle and Next.js proof

Exact-tarball bundle budgets keep React and app-owned UI/form peers external. Current package-owned gzip closures are approximately 0.7 KiB headless, 2.9 KiB Base UI/shadcn, 3.8 KiB MUI, 3.1 KiB Base UI + RHF, and 4.0 KiB MUI + RHF. CI rejects cross-renderer imports and size regressions.

A production Next.js 16 App Router/Turbopack consumer installs the exact tarball, builds and server-renders the shadcn field without MUI/Emotion and without `transpilePackages`, `serverExternalPackages`, or experimental `optimizePackageImports` configuration.

## Qualification

- 25 unit and adapter tests plus Chromium, Firefox, and WebKit typing, paste, autofill replacement, focus, form, narrow viewport, and automated WCAG checks.
- Strict declaration and SSR/runtime consumers from the exact tarball.
- MUI 7 + React 18 and MUI 9 + React 19 matrices.
- Base UI consumers without MUI/Emotion and MUI consumers without Base UI.
- Byte-identical npm registry artifact and provenance/signature verification through trusted OIDC publication.

Stable publication and npm `latest` promotion were explicitly authorized by the package owner on 2026-09-21.
